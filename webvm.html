What About Lockdown Browsers? THE SHORT ANSWER: YES

Lockdown browsers lock down the school's machine.
OnWorks isn't the school's machine.

A browser-based VM flips that entirely. When your "computer" is a Windows desktop running on a remote server inside a tab, the lockdown software on the host laptop has no idea what's happening inside it.
