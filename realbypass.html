STEP 1

Install Tampermonkey

Tampermonkey is a browser extension that lets you run custom scripts on websites.

  • Chrome: Install from Chrome Web Store
  • Firefox: Install from Firefox Add-ons
  • Edge: Install from Edge Add-ons

Once installed, you'll see the Tampermonkey icon in your browser toolbar.

STEP 2

Click the Tampermonkey icon → Create a new script.
