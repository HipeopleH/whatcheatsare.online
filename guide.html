Using the site is simple:

How to Use Bookmarklets

Bookmarklets are bookmarks that run JavaScript code. They're quick and easy to use.

1. Copy the bookmarklet code from the tool's website

2. Create a new bookmark in your browser

3. Paste the code as the URL

4. Click the bookmark when you're on the target site

5. Enjoy! 🎉

How to Use Chrome Extensions

1. Click the link to the Chrome Web Store

2. Click "Add to Chrome"

3. Pin the extension for easy access

4. Use it on the target site

⚠️ Some school Chromebooks block extensions. If that's the case, try a bookmarklet or web-based tool instead.

How to Use Web-based Tools

1. Click the website link

2. Follow the on-screen instructions

3. Usually just paste a game code or URL

How to Use Tampermonkey Scripts

1. Install the Tampermonkey extension from the Chrome Web Store

2. Click the script link (usually a .user.js file)

3. Tampermonkey will ask to install it — click "Install"

4. Enable the script and refresh the target page

🔧 Tampermonkey scripts only work if you have the extension installed. Make sure it's enabled!

How to Use External Tools

Some tools run locally on your computer. These are usually downloads from GitHub.

1. Download the file from GitHub

2. Run it on your computer

3. Follow the tool's specific instructions

⚠️ Only download external tools from trusted sources. Check the Discord server for reviews before running anything.

Safety Tips

🛡️ Avoid Detection

  • Don't use cheats during proctored exams
  • Clear your browser history after using tools
  • Use incognito/private mode
  • Don't brag about cheating — keep it low-key

🧪 Avoid Malware

  • Only use tools from trusted sources
  • Check the Discord server for reviews
  • Use uBlock Origin to block sketchy ads
  • Don't download suspicious .exe files

🌐 Use a VPN (if needed)

  • If a tool is blocked by your school, try a proxy or VPN
  • X-VPN is a good free option
  • Check the Proxies section for more options

Glossary

  • Bookmarklet — A bookmark that runs JavaScript code on a webpage
  • Tampermonkey — A browser extension that runs user scripts
  • Proxy — A service that hides your IP and bypasses filters
  • API-key — A key required to use a tool (often paid)
  • Undetected — The tool hasn't been flagged by the platform
  • Freemium — Free with optional paid features
  • GoGuardian / Securly — School monitoring software that blocks certain sites
