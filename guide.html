📘 Guide

A guide to navigating WCAO, understanding its categories, and using the site's resources.

Welcome

whatcheatsareonline.qd.je (WCAO) is a community-driven directory of online tools, resources, documentation, utilities, and other projects.

The homepage is designed to help you find a resource quickly, while individual pages provide more information about specific projects.

💡 Guide vs. Docs: This page explains how WCAO is organized. The Docs section contains more technical documentation for specific tools and projects.

Getting Started

Most WCAO pages follow the same basic workflow:

1. Find the category or tool you are looking for.

2. Open the tool's dedicated page.

3. Check its current status, compatibility, and notes.

4. Read the documentation before using unfamiliar software.

5. Check the project's official resources for changes or updates.

⚠️ WCAO is a directory, not a guarantee that every listed tool is current, safe, compatible, or available. Always check the individual page and source before trusting a resource.

Navigating WCAO

The homepage organizes resources into category cards. Selecting a card takes you to the relevant section or page.

Cheats

The Cheats category contains game and platform-related tools. Availability, compatibility, and behavior can change frequently as the platforms they interact with are updated.

⚠️ A tool being listed on WCAO does not mean it is currently compatible. Check the tool's status and version information before relying on it.

Common issues

  • The target platform updated.
  • A tool's backend went offline.
  • A script or extension no longer matches the current site.
  • A previously supported version is no longer supported.

Evadus

Evadus has its own dedicated section because it is a Windows desktop project with version-specific behavior and substantially more technical documentation than a typical web tool.

📄 Main page

Read /evadus for the project's overview, supported environment information, limitations, and technical explanation.

🔧 Help & troubleshooting

The dedicated Evadus Help page contains compatibility notes, troubleshooting information, and testing guidance.

⚠️ Evadus is version-dependent. Behavior observed on one Respondus LockDown Browser build should not automatically be assumed to work on another. Recorded or proctored sessions may also expose visible application windows.

Renderer troubleshooting

If Evadus reports that monitoring is active but the expected window does not appear, check the application's renderer configuration.

Renderer: Use a supported standard renderer rather than Protected. If the issue persists, record the Respondus version, selected renderer, and exact status/error message for troubleshooting.

WebVM

WebVM-related pages provide browser-accessible virtual-machine resources. These are useful for experimenting with a separate computing environment without installing a complete operating system locally.

/webvm

The WebVM page provides information about browser-based virtualized environments and their limitations.

/vm

The VM page provides another browser-based virtual machine resource. Availability and performance depend on the external service.

Important limitations

  • Browser VMs can be significantly slower than a local computer.
  • Files or installed software may not persist between sessions.
  • Clipboard, networking, graphics, and hardware access can be limited.
  • Do not assume a browser VM provides anonymity or invisibility.

Roblox Executors

The Roblox section contains Roblox-related tools and resources. Compatibility is particularly important here because Roblox updates can cause previously compatible software to stop working.

Version compatibility

If a tool requires an older Roblox build, the required version matters. Running a different Roblox version can result in unsupported-version errors, crashes, or the tool simply not functioning.

🔄 RDD: rdd.weao.gg is the WEAO RDD (Roblox Deployment Downloader) resource. Its interface provides options for downloading the latest or previous Roblox builds, including a Download Previous option for obtaining the previous build.

RDD also supports selecting a binary type and specifying a version hash. See the RDD interface itself for the currently available options.

Common Roblox compatibility problems

  • Unsupported version: the tool expects a different Roblox build.
  • Roblox updated: a previously working tool may need an update.
  • Version mismatch: the client and tool are not targeting the same build.
  • Tool update required: the software itself may need a newer release.
⚠️ Only use software and versions that you are permitted to use. Roblox version compatibility does not guarantee that a particular tool will work.

Security

Status & Compatibility

Status information is useful, but it should not be treated as a guarantee. A green status generally means the resource was recently observed as available; it does not guarantee that it will work on every device or version.

ONLINE The service is currently reported as available.
OFFLINE The service is currently reported as unavailable or has not responded normally.
VERSION DEPENDENT Compatibility depends on a specific software or platform version.
📌 When a tool suddenly stops working, check whether the underlying platform updated before assuming the tool itself is permanently broken.

Troubleshooting

The website does not load

  • Refresh the page.
  • Try another browser.
  • Check whether the external service is currently online.
  • Check the project's official status page or community.

A tool says it is unsupported

Check the tool's required version. Platform updates can invalidate older versions of software.

A userscript does nothing

  • Check that the userscript manager is enabled.
  • Check that the script is enabled.
  • Make sure the script's site permissions match the page you're using.
  • Check whether the target website changed.

A desktop application won't open

  • Check that your operating system is supported.
  • Check the application's documented version requirements.
  • Read any error message instead of repeatedly launching it.
  • Check whether the application requires an account or additional dependency.

Evadus says "Monitoring" but nothing appears

Check the renderer configuration. A supported standard renderer should be selected rather than Protected. If it still fails, record the Respondus version, renderer, and exact status message and consult Evadus Help.

Still broken?

Report the problem through the project's official community or the WCAO GitHub repository. Include the tool name, version, operating system, and exact error message when possible.

Safety & Privacy

Downloads

  • Prefer official project sources.
  • Be cautious with unknown executables and archives.
  • Check the file name, source, and publisher before opening software.
  • Do not enter passwords into an unfamiliar site simply because it appears in a directory.

Privacy

  • Do not upload private documents to services you do not trust.
  • Do not reuse important passwords on unfamiliar services.
  • Remember that browser-based services can still collect information.
  • A VM, proxy, or private browsing window does not automatically make you anonymous.

School and managed devices

⚠️ School-managed devices and networks can have policies, filtering, monitoring, or software restrictions that vary by district and device. WCAO does not guarantee that a resource will work on a managed device.

FAQ

Question Answer
Is everything on WCAO currently working? No. Tools can go offline or become incompatible after updates.
Why does a tool stop working after an update? The underlying platform may have changed its code, API, version, or security behavior.
Are all tools free? No. Some resources are free, while others may require accounts, paid features, or other access requirements.
What does VERSION DEPENDENT mean? It means the tool's compatibility depends on a particular software or platform version.
Where should I look for technical documentation? Start with the dedicated tool page or the Docs section.
Where is the Evadus troubleshooting guide? See /evadushelp.
Where can I report a broken resource? Use the project's community when available, or submit an issue/pull request through the WCAO GitHub repository.
Does WCAO guarantee that a listed resource is safe? No. Always evaluate the source, permissions, reputation, and behavior of software before using it.

Glossary

  • Bookmarklet — A bookmark containing JavaScript that runs in the browser.
  • API — An interface that allows software to communicate with another service.
  • API key — A credential used by an application to access an API.
  • Executor — Software designed to execute scripts in a particular environment.
  • OSINT — Open-Source Intelligence; research using publicly available information.
  • Proxy — An intermediary through which network requests can be routed.
  • Renderer — A component responsible for displaying or rendering content.
  • Userscript — A script designed to run through a userscript manager.
  • WebVM — A virtualized computing environment accessed through a web browser.
  • Freemium — A service with a free tier and optional paid features.
  • Version dependent — A resource whose behavior or compatibility depends on a particular software version.
