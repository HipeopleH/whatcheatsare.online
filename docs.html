📘 Technical Documentation

Everything you need to know about how the site works, how to contribute, and how to use the tools.

1. Overview

whatcheatsareonline.qd.je is a community-driven directory of cheats, tools, proxies, and AI assistants built by students, for students. The goal is simple: make it easy to find working tools for school, gaming, and productivity — without the sketchy ads, paywalls, or dead links.

The site is completely static (HTML + CSS + JavaScript) and hosted on GitHub Pages. All data is stored directly in the HTML, making it fast, lightweight, and easy to contribute to.

2. How It Works

Each tool is displayed as a card on the homepage. Cards contain:

  • Tool name — the name of the cheat or tool
  • Status — online (green) or offline (red)
  • Version — the current version number
  • Price — Free, Paid, API-key, or Freemium
  • Execution methods — how to use it (bookmarklet, extension, etc.)
  • Games/platforms — which platforms it works on
  • Links — website and Discord (if available)

The search bar filters cards by name, game, or platform. The filter modal lets you refine by price, type, execution method, detection status, and online/offline status.

3. Tool Card Structure

Each card uses data-* attributes to store metadata. These are used for filtering and search. 

<article class="exec-card"
         data-platform="X-Network"
         data-games="Blooket Kahoot Prodigy"
         data-methods="Bookmarklet Inspect Web-based"
         data-price="Free"
         data-type="Cheats"
         data-detection="Undetected"
         data-status="Online"
         data-version="8.0.0x">
    <!-- card content -->
</article>

Attribute Reference

  • data-platform — The name of the tool/cheat
  • data-games — Space-separated list of games or platforms it supports
  • data-methods — Space-separated list of execution methods (e.g., Bookmarklet, Web-based, Chrome Extension)
  • data-price — Pricing model: Free, Paid, API-key, Risky, or Free or $X/mo
  • data-type — Category: Cheats, AI, Proxies, or Other
  • data-detection — Undetected, Detected, Unknown, or File
  • data-status — Online, Offline, or Unknown
  • data-version — Version string (e.g., 8.0.0x, v3)
💡 Tip: When adding a new tool, make sure all data-* attributes are filled out correctly so the filters and search work properly.

4. Badges

Badges are used to quickly convey information about a tool.

  • v8.0.0x — Version badge (gray)
  • Free — Free badge (green)
  • $24/mo — Paid badge (blue)
  • API-key — API-key badge (yellow)
  • Free or $9/mo — Freemium badge (purple)
  • Risky — Risky badge (red)

To add a new badge style, define a class in .badge-price and reference it in the card: 

<span class="badge badge-price free">Free</span>

5. Filter System

The filter modal allows users to refine the tool list by:

  • Pricing — Free, Paid, API-key, Freemium options, Risky
  • Type — Cheats, AI, Proxies, Other
  • Execution Method — Bookmarklet, Web-based, Inspect, Tampermonkey, Chrome Extension, External, Code
  • Detection — Undetected, Detected, Unknown, File
  • Status — Online, Offline, Unknown

Filters are applied client-side using JavaScript. The badge on the filter button shows how many active filters are applied.

🔧 To add a new filter option, update the corresponding #pricingOptions, #typeOptions, #methodOptions, #detectionOptions, or #statusOptions section in the modal HTML.

6. Status Page

The /status page displays the current online/offline status of every tool on the site.

Currently, the statuses are hard-coded in the JavaScript SERVICES array. To update a status, edit the status property of the corresponding object: 

const SERVICES = [
    { name: "X-Network", status: "online" },
    { name: "IXLAutoAnswer", status: "offline" },
    // ...
];

In the future, this could be replaced with a dynamic backend or scheduled ping checks.

7. Contributing

This site is open-source and community-driven. Contributions are welcome!

How to add a new tool

  1. Fork the repository on GitHub
  2. Open index.html and find the section for the tool type (Cheats, AI, Proxies, Other)
  3. Copy an existing card and modify the data-* attributes and content
  4. Submit a pull request with a clear description of the new tool

How to report a broken tool

  • Open an issue on GitHub
  • Join the Discord and ping the mods
  • Submit a pull request with the updated status
⭐ Love the project? Leave a star on GitHub and share it with your friends!

8. Design System

The site uses a clean, minimal aesthetic with a light theme. Colors are defined as CSS variables in the :root selector: 

:root {
    --bg: #ffffff;
    --header: #ffffff;
    --card: #f5f5f5;
    --card-hover: #eeeeee;
    --border: #ddd;
    --text: #1a1d1f;
    --muted: #555;
    --green: #35d16f;
    --red: #ff4545;
    --blue: #4a7cf7;
    --yellow: #eab308;
    --purple: #8b5cf6;
    --gray: #888f91;
}

The site is fully responsive, with breakpoints at 750px for mobile devices.
